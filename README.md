# Instagram Clone

A full-stack photo-sharing app built as a bootcamp project. Users can sign up, log in, browse photos pulled from an external API and save favourites.

The code lives in two repos:

| Part | Stack | Repo |
| --- | --- | --- |
| Frontend | React, Vite | [Instagram-clone-FE](https://github.com/lyssandraa/Instagram-clone-FE) |
| Backend | Node.js, Express, Sequelize (MySQL), bcrypt + JWT auth | [Instagram-clone-BE](https://github.com/lyssandraa/Instagram-clone-BE) |
